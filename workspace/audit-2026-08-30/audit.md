# 知帧 ContextKit 产品体验审查

日期：2026-08-30

## 审查范围

- 流程：打开应用 → 添加视频 → 配置压缩与高级参数 → 开始处理 → 下载上下文包与压缩视频。
- 用户目标：用尽量少的判断成本，把大体积、多类型素材可靠地整理成可交给任意 LLM 的上下文。
- 可访问性目标：键盘和辅助技术能够理解主要控件；小字、状态反馈和错误恢复对普通用户可读。

## 流程步骤

1. **进入与添加素材｜健康但首屏偏展示化**
   - 证据：[01-start.png](01-start.png)
   - 优点：本地处理、支持格式、TXT/PNG 输出契约和 GPU 状态都很清楚。
   - 风险：大标题占据首屏较多空间，真正的上传与设置入口被向下推；日常高频使用会产生重复滚动。

2. **配置视频压缩｜能力完整但判断成本较高**
   - 证据：[02-compression.png](02-compression.png)
   - 优点：解析来源、保留策略、设备、分辨率、速度、质量和音频码率都有合理默认值。
   - 风险：普通用户需要理解 CRF/CQ、NVENC、码率等概念；缺少压缩后体积与耗时预估。

3. **高级配置｜功能扎实但参数密度过高**
   - 证据：[03-advanced.png](03-advanced.png)
   - 优点：使用原生表单与 details 结构；开关整行可点击，语义结构整体较好。
   - 风险：参数以技术类别组织，而不是按“会议、课程、视频理解、资料归档”等目标组织；辅助文字偏小、颜色偏淡。

4. **处理完成与下载｜结果明确但后续工作仍需手动完成**
   - 证据：[04-result.png](04-result.png)
   - 优点：进度、事件、主结果与保留的压缩视频都有清晰入口。
   - 风险：提示气泡遮挡了部分事件；本次短视频从 1.0 MB 压缩为 1.4 MB，系统没有自动放弃无收益压缩；没有预览、搜索、纠错、说话人标记或常用产物导出。

## 最重要的产品机会

### P0：先让大文件流程真正可靠

1. 分片与断点续传：按文件分块上传，支持暂停、恢复、失败块重试和校验；25 GB 不应依赖一次 XHR 请求。
2. 任务中心：展示最近任务、当前队列、暂停/取消、失败原因、仅重试失败文件、重新下载和清理。后端已有任务列表接口，可先补前端。
3. 处理前预检：显示总时长、预计耗时、所需磁盘、首次模型下载量、预计输出和风险提示。
4. 压缩收益保护：压缩后若文件变大或节省比例低于阈值，自动改用原文件并删除无收益副本；允许用户设置最小节省比例。

### P1：把“抽取成功”变成“直接可用”

1. 任务模板：会议纪要、课程学习、视频理解、论文/资料归档、批量 OCR。模板自动设置模型、时间戳、图片数量、抽帧和压缩；专家参数仍可展开覆盖。
2. 说话人分离：本地 diarization、说话人数量范围、说话人重命名，并把结果与 Whisper 时间戳对齐。
3. 可校对转写：搜索、点击时间戳定位、批量替换专有名词、标记低置信度片段，导出 TXT/MD/SRT/VTT/JSONL。
4. 智能视觉筛选：场景变化 + OCR 信息量 + 感知哈希去重；处理前预览候选帧，允许删除、固定或排序。
5. 结构化上下文：保留当前 TXT/PNG 默认契约，同时可选生成带 source/page/start/end/confidence 的 JSONL 和分块清单，方便 RAG 与长上下文模型。

### P2：扩大真实工作入口

1. 文件夹与批处理：拖入文件夹、合并为一个上下文包或逐文件输出、批量命名和并发数控制。
2. URL 输入：可选支持网页与公开视频地址，并明确网络访问与版权提示；默认仍保持本地文件模式。
3. 项目库：同一项目追加新来源，只处理新增或变化文件，保留版本与来源引用。
4. 模型管理：显示已安装模型、下载大小、显存需求、最近速度、缓存位置和一键清理；首次运行前允许预下载。
5. 存储策略：磁盘余量预警，按任务选择“保留原文件 / 仅保留结果 / N 天后自动清理”。

## 可访问性与易用性改进

- 为视频压缩开关提供稳定的可访问名称；当前辅助技术只读到“关闭/已开启”，没有读到“视频压缩”。
- 将 9～10px 的帮助文字提高到至少 12px，并复核浅灰文字对比度。
- 结果完成时避免 Toast 覆盖事件日志；把成功信息放入结果卡本身。
- 为不可用的“开始整理”按钮显示原因，例如“请先添加文件”或“文件超过本次上限”。
- 增加“简洁模式”：首次和普通用户只显示任务模板、质量和输出数量；技术参数放到专家模式。

## 不建议现在做

- 不建议先内置完整聊天机器人或绑定某一家云端 LLM。当前产品的差异化是本地、模型无关、忠实抽取。
- 不建议继续堆更多冷门格式，除非有真实失败样本。可靠上传、任务恢复、说话人和结果校对的价值更高。
- 不建议默认生成摘要或结论；应作为显式可选产物，并始终保留可追溯的原始抽取结果。

## 证据限制

- 本次检查覆盖桌面端单个视频的完整流程，没有验证移动端、屏幕阅读器实际朗读、200% 缩放和 25 GB 真实传输。
- 未对颜色做仪器化 WCAG 对比度测量，因此对比度属于可见风险，不是合规结论。
- 压缩变大来自短测试视频，不能代表所有素材，但足以证明需要“无收益保护”。
